# Chapter 4 : Application Package

## Word Processing

**Word processing** means using a computer to **type, edit, format, store, and print** documents.

Examples of word processors: Word Star, Word Perfect, MS-Word.

---

## MS-Word

- A **word processing** software made by **Microsoft Corp. (USA)**.
- Part of the **MS-Office** package.
- Used to create letters, question papers, booklets, thesis, pamphlets, etc.
- Application name: `winword.exe`
- File extension: `.doc` (Word 2003 or older) / `.docx` (Word 2007 & above)

### Starting MS-Word

- Start → All Programs → MS-Office → Microsoft Word
- **Or:** Start → type `winword` → Enter
- **Or:** `Windows key + R` → type `winword` → Enter

### Difference between Save and Save As

| Save | Save As |
|------|---------|
| `Ctrl + S` | `F12` |
| Saves changes into the **same** file | Saves the document with a **new name/location** |
| Asks for file name only the first time | Always asks for file name |
| Original file gets overwritten/updated | Original file stays unchanged; a new copy is created |
| Used to update existing work | Used to create a duplicate/backup or new version |

## Mail Merge (Mailings Tab)

**Mail Merge** is a feature that lets you send the **same letter to many different people**, where the message stays the same but the **name, address, and other details change** for each person. Instead of typing a separate letter for every person, Word automatically combines one letter with a list of names/addresses to create many personalized copies at once. It saves a lot of time when sending invitations, notices, or letters to a large number of people.

### The 3 Documents Involved in Mail Merge

1. **Main Document** — Contains the actual **letter/content** that is common to everyone (e.g., an invitation letter, notice, or circular).
2. **Data Document (Data Source)** — Contains the **list of variable details** such as name, address, phone number of each recipient. Each person's record is like a row of data.
3. **Merged Document** — The **final output** created by combining the Main Document with the Data Document. Word generates one page/letter per person, each with their own details inserted automatically.

### Steps to Perform Mail Merge

1. Type the main letter and save it (leave blank spaces where name/address should go).
2. Click on the **Mailings Tab**.
3. Click **Select Recipients** → **Type New List** (to create a new data list).
4. Click **Customize Columns** → delete unwanted fields, rename or add new fields (e.g., Name, Address, Phone) → click **OK**.
5. Type the details of the first person → click **New Entry** to add more. Repeat for all recipients.
6. After entering all records, click **Close**.
7. A **Save As** dialog appears — type a file name and click **Save** to save the data document.
8. Place the cursor at the required position in the letter → click **Insert Merge Field** to insert fields like «Name», «Address», etc.
9. Click **Preview Results** to check how each letter will look (browse records using navigation arrows).
10. Click **Finish & Merge** → **Edit Individual Documents** → tick **All** → click **OK**.
11. The final merged document is created with a separate letter for each person. Save and print.

### Why Mail Merge is Useful

- Saves time — no need to type the same letter again and again.
- Reduces errors, since names/addresses come directly from the data list.
- Useful for invitations, exam admit cards, notices, certificates, and marketing letters.
