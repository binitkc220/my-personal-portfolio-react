Examples of word processors: Word Star, Word Perfect, MS-Word.

| Save | Save As |
|------|---------|
| `Ctrl + S` | `F12` |
| Saves changes into the **same** file | Saves the document with a **new name/location** |

## Mail Merge (Mailings Tab)

**Mail Merge** is a feature that lets you send the **same letter to many different people**, where the message stays the same but the **name, address, and other details change** for each person. Instead of typing a separate letter for every person, Word automatically combines one letter with a list of names/addresses to create many personalized copies at once. It saves a lot of time when sending invitations, notices, or letters to a large number of people.

### The 3 Documents Involved in Mail Merge

1. **Main Document** — Contains the actual **letter/content** that is common to everyone (e.g., an invitation letter, notice, or circular).
2. **Data Document (Data Source)** — Contains the **list of variable details** such as name, address, phone number of each recipient. Each person's record is like a row of data.
3. **Merged Document** — The **final output** created by combining the Main Document with the Data Document. Word generates one page/letter per person, each with their own details inserted automatically.

### Steps to Perform Mail Merge

1. Type the main letter and save it (leave blank spaces where name/address should go).
2. Click on the **Mailings Tab**.
3. Click **Select Recipients** → **Type New List** (to create a new data list).
4. Click **Customize Columns** → delete unwanted fields, rename or add new fields (e.g., Name, Address, Phone) → click **OK**.
5. Type the details of the first person → click **New Entry** to add more. Repeat for all recipients.
6. After entering all records, click **Close**.
7. A **Save As** dialog appears — type a file name and click **Save** to save the data document.
8. Place the cursor at the required position in the letter → click **Insert Merge Field** to insert fields like «Name», «Address», etc.
9. Click **Preview Results** to check how each letter will look (browse records using navigation arrows).
10. Click **Finish & Merge** → **Edit Individual Documents** → tick **All** → click **OK**.
11. The final merged document is created with a separate letter for each person. Save and print.

### Why Mail Merge is Useful

- Saves time — no need to type the same letter again and again.
- Reduces errors, since names/addresses come directly from the data list.
- Useful for invitations, exam admit cards, notices, certificates, and marketing letters.

## Features of Word Processor / MS-Word

1. **Text Editing** — Type, insert, delete, copy, cut, and paste text easily without retyping the whole document.
2. **Text & Paragraph Formatting** — Change font, size, color, style (bold/italic/underline), alignment, line spacing, and indentation.

4. **Spelling & Grammar Check** — Automatically detects and corrects spelling and grammatical mistakes (`F7`).
5. **Find & Replace** — Quickly searches a word and replaces it throughout the whole document.
6. **Tables** — Create tables with rows and columns, and perform simple calculations using formulas.
7. **Inserting Objects** — Insert pictures, shapes, charts, SmartArt, WordArt, symbols, and equations.
8. **Header, Footer & Page Numbers** — Add repeating text and automatic page numbers on every page.
9. **Page Setup** — Set margins, orientation, paper size, columns, borders, and watermark.
10. **Print & Print Preview** — View the document before printing and print any number of copies.

## Spreadsheet

A **spreadsheet** (also called a **worksheet**) is a grid that organizes data into **rows and columns**. It is used to **store, calculate, analyze, and present** numerical data in the form of reports and charts.

- **Rows** are horizontal and numbered (1, 2, 3 …).
- **Columns** are vertical and lettered (A, B, C …).
- When a value in a cell changes, all related formulas are **recalculated automatically**.
- Widely used for marksheets, salary sheets, budgets, bills, inventory, and accounts.

| Version | Columns | Rows |
|---------|---------|------|
| Excel 2003 | 256 | 65,536 |
| Excel 2007 & above | 16,384 | 10,48,576 |

Examples of spreadsheet packages: **MS-Excel, Lotus 1-2-3, VisiCalc, Google Sheets, LibreOffice Calc**.

### Basic Terms

| Term | Meaning |
|------|---------|
| **Workbook** | An Excel file that contains one or more worksheets. |
| **Worksheet** | A single sheet of rows and columns inside a workbook (Sheet1, Sheet2 …). |
| **Cell** | The intersection of a row and a column; the basic unit where data is entered. |
| **Cell Address** | Column letter + row number that identifies a cell (e.g. `B5`). |
| **Active Cell** | The currently selected cell, shown with a dark border. |
| **Range** | A group of adjacent cells (e.g. `A1:D10`). |
| **Formula** | A calculation entered in a cell, always starting with `=` (e.g. `=A1+B1`). |
| **Function** | A ready-made (built-in) formula (e.g. `=SUM(A1:A10)`). |

## MS-Excel

- A popular **spreadsheet program** developed by **Microsoft Corp. (USA)**.
- Part of the **MS-Office** package and runs in the Windows environment.
- Combines **worksheets, charts, database/list operations, and programming (macros)** in one software.
- Used for **managing, calculating, analyzing, and presenting data** in tables and graphs.
- Application name: `excel.exe`
- File extension: `.xls` (Excel 2003 or older) / `.xlsx` (Excel 2007 & above)

### Features of MS-Excel

1. **Windows-Based Application** — Has ribbon/toolbars, shortcut menus, AutoCorrect, online help, and wizards like other Windows programs.
2. **Workbook & Worksheets** — One file (workbook) can hold multiple worksheets, so related data stays organized in one place.
3. **Formulas & Functions** — Hundreds of built-in functions (mathematical, statistical, date & time, logical) for fast and accurate calculations.
4. **Automatic Recalculation** — Results update automatically when any input value is changed.
5. **Charts** — Presents data graphically using Bar, Column, Line, Pie, Area, and other chart types.
6. **Formatting** — Format numbers, fonts, borders, colors, and alignment; conditional formatting highlights data based on rules.
7. **Sorting & Filtering** — Arrange data in ascending/descending order and show only the records that meet a condition.
8. **Data Validation** — Sets rules for data entry (e.g. marks only between 0–100) to prevent wrong input.
9. **AutoFill / Data Series** — Automatically fills sequences like 1, 2, 3 … or Jan, Feb, Mar ….
10. **Printing & Page Setup** — Set margins, orientation, paper size, and header/footer before printing.

### Starting MS-Excel

- Start → All Programs → MS-Office → Microsoft Excel
- **Or:** Start → type `excel` → Enter
- **Or:** `Windows key + R` → type `excel` → Enter

## Functions in Excel

**Functions** are **ready-made formulas**. Every function starts with `=`.

### Mathematical Functions

| Function | Use | Example → Result |
|----------|-----|------------------|
| `ABS()` | Converts negative to positive | `=ABS(-5)` → 5 |
| `SUM()` | Adds values | `=SUM(A2:F2)` |
| `PRODUCT()` | Multiplies values | `=PRODUCT(2,3,4)` → 24 |
| `PI()` | Returns value of π | `=PI()` → 3.14159… |
| `POWER()` | Number raised to a power | `=POWER(2,3)` → 8 |
| `SQRT()` | Square root | `=SQRT(25)` → 5 |

### Statistical Functions

| Function | Use | Example → Result |
|----------|-----|------------------|
| `AVERAGE()` | Arithmetic mean | `=AVERAGE(12,4,2,6)` → 6 |
| `MAX()` | Largest value | `=MAX(5,9,2)` → 9 |
| `MIN()` | Smallest value | `=MIN(5,9,2)` → 2 |
| `MEDIAN()` | Median value | `=MEDIAN(5,9,2)` → 5 |
| `MODE()` | Repeated value | `=MODE(2,5,9,2)` → 2 |

### Date & Time Functions

| Function | Use | Example |
|----------|-----|---------|
| `TODAY()` | Current date | `=TODAY()` |
| `NOW()` | Current date and time | `=NOW()` |

### Logical Functions

| Function | Use | Syntax |
|----------|-----|--------|
| `AND()` | TRUE only if **all** conditions are TRUE | `=AND(logical1, logical2, …)` |
| `IF()` | Returns one value if TRUE, another if FALSE | `=IF(condition, value_if_true, value_if_false)` |

## Sort & Filter (Data Tab)

- **Sort** — Arranges data in **Ascending** (A–Z, 0–9) or **Descending** (Z–A, 9–0) order.
  - Select data → Data Tab → **Sort** → choose column & order → OK
- **Filter** — Shows only the records that match a condition; others are hidden.
  - Select data → Data Tab → **Filter** → click drop-down arrow on column heading → choose condition
  - Types: **AutoFilter** (quick, drop-down based) and **Advanced Filter** (complex conditions)

## Slide Transition vs Animation

| Slide Transition | Animation |
|------------------|-----------|
| Effect applied when **moving from one slide to the next** | Effect applied to **text/objects within a slide** |
| Transitions Tab | Animations Tab |
| Can set sound, speed, on-click or auto timing | Types: **Entrance, Emphasis, Exit, Motion Path** |

- **Transition:** View → Slide Sorter → `Ctrl + A` → Transitions Tab → choose effect, sound, timing → `F5` to play
- **Animation:** Select text/object → Animations Tab → choose effect (**Animation Pane** to manage order/timing)
